Actividad 15: Exiftool

La fotografía como testigo: extracción de metadatos GPS para geolocalización

Elaborado por: José Carlos Ojeda Camacho

Detalles del Reporte

Objetivo

Analizar e interpretar los metadatos incrustados en un documento de texto y un archivo de imagen utilizando la herramienta de línea de comandos ExifTool, con el fin de extraer información crítica sobre su creación, edición y geolocalización.

Herramientas Utilizadas

  • Software: ExifTool (versión de consola / línea de comandos)
  • Archivos de análisis: WOA database application form.docx y XiaomiMiA2Lite.jpg

Procedimiento General

Para llevar a cabo esta práctica, el primer paso consistió en descargar y configurar la herramienta de línea de comandos ExifTool en el equipo de trabajo. Con el fin de facilitar la ejecución de los comandos, los archivos de prueba fueron ubicados en el mismo directorio que el ejecutable del programa. Posteriormente, se abrió una consola de comandos (PowerShell/CMD) apuntando directamente a la ruta de trabajo correspondiente, desde donde se introdujeron las instrucciones para la extracción de datos.

Parte I. Análisis de metadatos del fichero WOA database application form.docx

Para la primera fase del ejercicio, se ejecutó el comando exiftool "WOA database application form.docx". La consola arrojó una lista completa con las propiedades ocultas del documento de Microsoft Word. A partir de la revisión de estos resultados, se logró identificar información clave sobre la estructura y autoría del archivo.

Cuestionario Analítico:
  1. ¿Cómo categorizó el archivo INTERPOL?
    Unclassified
  2. ¿Qué template fue utilizado para la elaboración del archivo por parte de INTERPOL?
    G03 Basic Doc SP.dotx
  3. ¿Cuál fue el tiempo total de edición del fichero?
    45 minutes
  4. Identifique la Compañía propietaria del fichero.
    OIPC - INTERPOL
  5. ¿Quién realizó la última modificación del fichero?
    Carolyn Lejeune
  6. ¿Cuál fue la fecha de creación del fichero en investigación?
    2026:10:27 21:57:08-06:00
  7. De acuerdo al análisis de matadatos del fichero de INTERPOL, identifique el creador del mismo.
    Carolyn Lejeune

Parte II. Análisis de metadatos del fichero XiaomiMiA2Lite.jpg

Durante la segunda fase, se procedió a extraer los datos EXIF de la imagen ejecutando el comando exiftool XiaomiMiA2Lite.jpg. El análisis de los resultados permitió determinar las especificaciones técnicas de la captura y la geolocalización exacta del dispositivo en ese momento.

Cuestionario Analítico:
  1. ¿Cuál fue la apertura ISO utilizada?
    La apertura ISO fue de 100.
  2. ¿Cuál es la longitud focal de la cámara con la que fue capturada la imagen?
    3.8 mm (35 mm equivalent: 26.0 mm)
  3. ¿Señale si se utilizó la captura con Flash para obtener la imagen?
    No se utilizó, el registro indica Flash: Off, Did not fire"
  4. Señale la fecha de creación del archivo.
    2026:10:27 21:57:08-06:00
  5. Identifique los datos de ubicación GPS y señale el lugar exacto dónde la fotografía fue tomada.
    • GPS Latitude Ref: North
    • GPS Longitude Ref: West
    • GPS Altitude Ref: Unknown (2.2)
    • GPS Time Stamp: 17:11:42
    • GPS Processing Method: ASCII
    • GPS Date Stamp: 2020:05:28
    • GPS Altitude: 96.7 m Below Sea Level
    • GPS Date/Time: 2020:05:28 17:11:42Z
    • GPS Latitude: 51 deg 15' 12.99" N
    • GPS Longitude: 0 deg 32' 21.93" W

Al ingresar las coordenadas resultantes en el sistema de navegación de Google Maps, se pudo comprobar que el lugar exacto de la captura se sitúa en la ciudad de Londres, Reino Unido, específicamente en las inmediaciones del lago The Serpentine, ubicado en Hyde Park / Kensington Gardens.

Eliminación de Metadatos

Para concluir la actividad y cumpliendo con los protocolos de limpieza de información confidencial, se procedió a eliminar todos los metadatos incrustados en la fotografía analizada mediante la ejecución del comando exiftool -all= XiaomiMiA2Lite.jpg. La herramienta confirmó la actualización exitosa del archivo, purgando por completo los datos EXIF y de GPS, y generando de forma automática un archivo de respaldo con el nombre original modificado.

Comprobación de eliminación:

PS C:\Users\charl\Downloads\exiftoolgui>./exiftool -all C:\Users\charl\Downloads\exiftoolgui\infocrim\XiaomiMiA2Lite.jpg
